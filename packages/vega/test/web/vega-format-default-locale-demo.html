Accessing Vega's Default Locale

This demo shows how to access the existing default locale (US English) without creating a custom one.

1. Default Number Formatting

// Get the default number format locale (no arguments) const defaultNumberLocale = vega.formatLocale(); const numberFormatter = defaultNumberLocale.format('$,.2f'); console.log(numberFormatter(1234.56));

2. Default Time Formatting

// Get the default time format locale (no arguments) const defaultTimeLocale = vega.timeFormatLocale(); const timeFormatter = defaultTimeLocale.timeFormat('%A, %B %e, %Y'); console.log(timeFormatter(new Date()));

3. Combined Default Locale

// Get the combined default locale (no arguments) const defaultLocale = vega.defaultLocale(); const combinedFormatter = defaultLocale.format(',.2f'); console.log(combinedFormatter(9876.54));

4. More Number Format Examples

const locale = vega.formatLocale(); console.log(locale.format('.0%')(0.123)); // Percentage console.log(locale.format(',.0f')(1234567)); // Thousands separator console.log(locale.format('.3s')(1500000)); // SI prefix

5. More Time Format Examples

const locale = vega.timeFormatLocale(); const now = new Date(); console.log(locale.timeFormat('%Y-%m-%d')(now)); // ISO date console.log(locale.timeFormat('%I:%M %p')(now)); // 12-hour time console.log(locale.timeFormat('%B %Y')(now)); // Month and year
